# Agent Reliability Lab: guided demonstration

Controlled fault experiments over fictional requirements and a deterministic fixture provider. The default demo makes no paid model calls.

## A focused walkthrough

1. **Choose a task.**
2. **inject a fault.**
3. **compare runs.**
4. **inspect integrity and output.**

Pause on the evidence at each decision: leases and fencing; checkpoint integrity; artifact-bound verification.

## Interactive access

The application is available in Mohammed's local Demo Studio. This repository deliberately does not contain a runnable source distribution. A reviewer can inspect the included materials immediately or request a guided limited-demo session through [the portfolio](https://mohammed-ab.github.io/).

## Boundaries

Fixture faults demonstrate specific failure modes; they are not a benchmark of all real models or an availability guarantee. The baseline is intentionally unsafe inside the experiment only.
